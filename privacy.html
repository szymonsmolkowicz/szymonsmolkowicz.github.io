Polityka prywatności

Aplikacja: CRM Szymon n8n. Obowiązuje od: 17 listopada 2026.

Kto używa aplikacji

Aplikacja jest prywatnym narzędziem jednej osoby — właściciela konta GitHub szymonsmolkowicz — i łączy się wyłącznie z jego własnymi kontami Google. Nie jest oferowana innym użytkownikom.

Jakie dane są odczytywane

  • Gmail (tylko odczyt): nagłówki i treść wiadomości, żeby wyszukać ważne sprawy i uporządkować pocztę właściciela.
  • Kalendarz Google (tylko odczyt): wydarzenia właściciela.
  • Google Tasks (tylko odczyt): zadania właściciela.
  • Podstawowe dane konta (adres e-mail), żeby wiedzieć, które konto jest podłączone.

Jak dane są używane i przechowywane

Dane są przetwarzane wyłącznie na urządzeniach właściciela i tylko na jego potrzeby. Tokeny dostępu są przechowywane w zaszyfrowanym Pęku kluczy systemu macOS. Dane nie są sprzedawane, udostępniane osobom trzecim ani używane do reklam.

Korzystanie z informacji otrzymanych z interfejsów API Google jest zgodne z Zasadami dotyczącymi danych użytkownika w usługach interfejsu API Google, w tym z wymaganiami dotyczącymi ograniczonego użytkowania (Limited Use).

Cofnięcie dostępu

Dostęp można w każdej chwili cofnąć na stronie myaccount.google.com/permissions.
